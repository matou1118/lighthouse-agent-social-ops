# 平台风控红线（运营行为层）

> 这份和 `违规词红线.md` 是两回事：
> 那份管**内容写什么**，这份管**账号怎么操作**。
> 两个都会导致封号，但这份翻车更彻底——**一次整组。**

---

## 一、矩阵关联的四重信号

小红书打击矩阵账号，靠的是**关联分析**，不是单看某个行为。
下面四个信号任意叠加两个以上，就进入可疑名单。

| 信号 | 具体表现 | 如何被识别 |
|---|---|---|
| **关注关系** | 多个号互相关注 | 关注关系图分析，闭合小圈子一眼可见 |
| **群聊重合** | 把多个号拉进同一个群 | 群成员 = 关注关系，双重印证 |
| **设备/IP** | 同一 IP 或设备登录多个号 | 设备指纹 + IP |
| **时间相关** | 一个号发了，其它号立刻互动 | 行为时间序列分析 |

**⛔ 绝对不要做：把自己的多个号拉进一个群。**
它同时命中「关注关系」和「群聊重合」两条，是最强的自证。

## 二、官方处置力度

```
2024-12  一个月处置 125.97 万个账号
         含 10 万粉以上 252 个、1 万粉以上 4941 个
         官方定性：「黑灰产矩阵账号……前期养号，后期转售账号」
         处置方式：永久封禁

2025-10  KOS 矩阵封号潮
```

处置是**整组**，不是单个。一个号被判定，同 IP / 同设备 / 互关的号一起处理。

## 三、明确禁止清单

| ⛔ 禁止 | 原因 |
|---|---|
| 自己的号互相点赞、收藏、评论 | 时间相关性 + 关注关系 |
| 建群把多个号拉一起 | 关联信号叠加 |
| 同一 IP 短时间内登录多个号 | 设备关联 |
| 一个号发布后其它号立刻互动 | 行为时间模式 |
| 多个号同时段发布 | 同上 |
| 用同一个手机号/邮箱注册多个号 | 身份关联 |
| **跨区域接单** | **业务只覆盖绵阳及所属县市，接了外地的单是违规** |

### ⛔ 服务范围：绵阳地区（推广范围是全省）

**这是两层，别混：**

| | 范围 | 能做 |
|---|---|---|
| **推广** | 四川省 | 内容面向全省，谁都能看、都能咨询 |
| **服务** | 绵阳地区 | 宽带安装 / 办卡**只能落在绵阳** |

**服务范围**：涪城 / 游仙 / 安州 / 江油 / 三台 / 盐亭 / 梓潼 / 北川 / 平武。

**所以：**

| | 例子 | 判断 |
|---|---|---|
| ✅ 提及 | 「在成都上班的绵阳人，给老家装宽带」 | 可以（服务地址在绵阳） |
| ✅ 提及 | 「在成都工作，给涪城的爸妈装宽带」 | 可以 |
| ✅ 提及 | 「家里在绵阳的，人在外地也能办」 | 可以 |
| ❌ 承诺 | 「成都也能装」 | **不行**（服务不在成都） |
| ❌ 承诺 | 「四川全省都能办」 | **不行** |
| ❌ 承诺 | 「不限地区，都能上门」 | **不行** |
| ❌ 招揽 | 「成都的朋友可以找我」 | **不行**（招揽了服务不了的人） |

> `scan_local.py` 检查这条：**承诺类 / 招揽类表述硬拦（阻断发布），
> 提到外地但没有"给老家装"的语境只提醒。**

**在四川其他城市的人不是不能看内容** —— 是**不能承诺给他们装**。
如果对方家里在绵阳，那完全能做，而且是最好的客户。

## 四、正确做法

| ✅ 该做 | 为什么 |
|---|---|
| **轮换制**：每轮只有一个号活跃 | 账号间无可识别的时间关联 |
| 各号独立运营，**互相之间零互动** | 不形成关注/行为关系 |
| 分天登录，一天最多 1-2 个号 | 避免设备/IP 关联 |
| 内容靠自然增长 | 真实用户的互动权重远高于自刷 |
| **公开评论**（在别人热帖下写干货并设为公开） | 合法曝光路径，别人点进主页能看到 |

## 五、真实曝光路径（替代自刷）

小红书的权重来自**真实互动**，自刷那点量算法一眼识破。真正有效的：

1. **内容值得收藏** —— 收藏率是推荐算法最看重的信号
2. **评论区经营** —— 在有热度的话题下写有价值的评论
3. **公开评论功能** —— 把有价值的评论设为公开，累积主页可见度
4. **自然关注** —— 靠内容一致性，不靠互相点关注

## 六、功能事实澄清

### 「转发」不能形成主页内容

小红书的「转发」= 分享到站外或私信/群，**不会出现在你的主页**。
它没有微博那种「转发到我自己主页」的能力。

所以多个号之间**无法通过转发互相供给内容**。每个号想有内容，
只能自己发。

### 各动作的实际效果

| 动作 | 是否产生主页内容 | 备注 |
|---|---|---|
| 发布笔记 | ✅ | 唯一的原创路径 |
| 评论（设为公开） | ✅ 部分 | 会显示在主页评论tab |
| 收藏 / 点赞 | ❌ | 仅互动信号，**自刷无意义** |
| 分享到群/私信 | ❌ | 纯聊天行为 |

## 七、自检

上线前对着这几条过一遍：

```
[ ] 有没有建群把我自己的号拉在一起？
[ ] 我的号之间有没有互相关注？
[ ] 有没有哪个号在别的号发布后立刻去点赞/收藏？
[ ] 是不是在同一个 IP/设备上登录了多个号？
[ ] 有没有多个号在同一时间段发布？
[ ] 有没有用同一手机号注册多个号？
```

**任意一条为「是」→ 立即停止，这是整组被封的路径。**
