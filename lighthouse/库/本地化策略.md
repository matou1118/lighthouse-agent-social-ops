# 本地化策略（四川推广 · 绵阳服务）

> **这份文件改变所有内容的写法。**

## 一、两层范围（最重要，先看这个）

| | 范围 | 意思 |
|---|---|---|
| **推广范围** | **四川省** | 内容可以面向全省的人 |
| **服务范围** | **绵阳地区** | 宽带安装 / 办卡只能落在绵阳 |

```
四川任何地方的人都可以看到内容、可以咨询
        ↓
但真正办理时，安装地址和号码归属必须在绵阳
```

**这决定了内容怎么写：**
- ✅ 可以面向全省的人说话（在成都上班的、在绵阳有老家的）
- ✅ 可以提到四川其他城市 —— 作为**人群描述**，不是服务范围
- ❌ 不能承诺绵阳以外的安装/办卡

**四种典型客户：**

| 客户 | 服务地址 | 能做吗 |
|---|---|---|
| 绵阳本地人 | 绵阳 | ✅ 最直接 |
| 在外打拼的绵阳人（给老家装） | 绵阳 | ✅ 很值钱 |
| 家里人在绵阳的外地人 | 绵阳 | ✅ |
| 四川其他市的普通客户 | 非绵阳 | ❌ 服务不了，别招揽 |

**所以内容的落点是**：面向全省的受众，但**只承接服务地址在绵阳的**。

## 二、为什么本地打法更划算

| | 通用打法（"宽带怎么选"） | 本地打法（"绵阳宽带怎么选"） |
|---|---|---|
| 竞争 | 全国大号在打，新人难出头 | **低一个量级** |
| 流量 | 天花板高，但触达不到能办的人 | 天花板低，但**都是潜在客户** |
| 转化 | 看完就划走 | 评论区能直接对话，能到店 |
| 小红书推荐 | 全国流量池 | **同城流量池**，优先推给附近的人 |

**核心机制：小红书按内容里的地域信号决定推给谁。**
不带绵阳信号，内容会被推给全国的人 —— 其中绝大多数办不了。

## 三、绵阳行政区划（服务范围）

```
3 个区   涪城区 · 游仙区 · 安州区（原安县）
1 个市   江油市（县级市）
5 个县   三台县 · 盐亭县 · 梓潼县 · 北川羌族自治县 · 平武县

区号 0816
```

**能办卡/装宽带的只有这里。** 四川其他市可以做内容触达，
但**不承接那边的业务**。

**覆盖能力也不是均匀的。** 城区（涪城、游仙）最好，
安州、江油次之，北川、平武这类山区县可能有覆盖限制 ——
**涉及具体区域的内容，先跟联通对接人确认，别自己假设。**

## 四、内容的三个本地信号

每条内容至少中两个：

### ① 标题带地域词

```
❌ 装宽带要准备什么
✅ 绵阳装宽带要准备什么
✅ 在绵阳租房装宽带，这几样提前备好
```

地域词位置：**尽量靠前**（绵阳 / 涪城 / 游仙 / 江油 / 三台…）

### ② 正文有本地场景

地标、商圈、小区、高校 —— 具体的比笼统的好。

```
❌ 装修好的房子装宽带要注意
✅ 涪城这边新装修的房子，弱电箱位置经常留错，装宽带时很麻烦
```

### ③ 话题标签带本地

```
#绵阳 #绵阳生活 #绵阳租房 #绵阳同城 #绵阳宽带
```

**必带 #绵阳** —— 这是进同城流量池最直接的信号。

## 五、通用词与本地词混合

不能全用本地词（太窄，流量池太小），也不能全用通用词（推不到本地人）。

| 类型 | 用途 | 例子 |
|---|---|---|
| **通用词** | 找内容形态、看什么话题本身有热度 | 宽带安装、装宽带、宽带怎么选 |
| **本地词** | 验证本地有没有人搜、竞争如何 | 绵阳宽带、绵阳装宽带、绵阳租房 |

**采集时两层都采**，但内容里的地域信号必须有。

## 六、外延人群：在外打拼的绵阳人

**这是本地推广最容易被忽略、但很值钱的一个角度。**

服务地址只覆盖绵阳，但**客户不一定人在绵阳**：

```
在成都上班，给涪城老家的爸妈装宽带   ← 服务地址在绵阳 ✅
在绵阳租房，人在外地先远程问好        ← 服务地址在绵阳 ✅
给老家的房子装，以后回去住            ← 服务地址在绵阳 ✅
```

**在成都的绵阳人很多**，他们的需求是真实的：给老家装、给父母装、
给朋友推荐。这些人**能打电话、能扫码、能付钱**，服务落地全在绵阳。

### ⚠️ 但必须区分「提及」和「承诺」

| | 例子 | 判断 |
|---|---|---|
| ✅ 提及 | 「在成都上班的绵阳人，给老家装宽带要注意这几样」 | 可以。服务地址还是绵阳 |
| ✅ 提及 | 「在成都工作，给涪城的爸妈装宽带」 | 可以 |
| ❌ 承诺 | 「成都也能装，绵阳成都都可办」 | **不行。承诺了做不了的事** |
| ❌ 承诺 | 「四川全省都能办」 | **不行** |
| ❌ 承诺 | 「不限地区，都能上门」 | **不行** |

http://`scan_local.py` 会检查这条：
- **承诺类表述 → 硬拦**（阻断发布）
- **提到外地但没有"给老家装"的语境 → 只提醒**，不阻断

### 这个角度的写法

```
标题：在成都上班，给绵阳老家装宽带要注意什么
     绵阳人在成都，怎么给涪城老家把宽带装好

正文：开头承认在外打拼的处境 → 讲清楚"你人不在绵阳也能办"
      → 重点讲流程（谁去开门、怎么跟师傅对接、父母不懂怎么办）
```

**关键是把场景讲透**：人不在本地、父母年纪大、只能远程沟通 ——
这些是这个人群真实的麻烦，讲到了就有共鸣。

**同时必须带绵阳地域词**（服务地址），标题里两个地名都出现最好。

## 八、本地推广的独特优势

**评论区就是转化位。**

通用内容里，用户问"多少钱"你只能答"去官方 App 查"。
本地内容里，用户问"涪城能装吗"，你可以答：

```
✅ 「涪城城区覆盖没问题，具体到你的小区建议在联通官方 App 里
    输地址查一下，或者去附近营业厅问，资费也是以官方为准」
```

**既合规，又真的帮到人，还能引导到线下。** 这是本地推广最值钱的地方。

## 九、风险提示
| 风险 | 说明 |
|---|---|
| **跨区域销售** | 只能做绵阳。内容里别暗示能做外地，接了外地的单是违规 |
| **覆盖承诺** | 不承诺"一定能装"。用"建议在官方 App 查你的地址" |
| **县区差异** | 不同区县资费/活动可能不同，**不报具体数字** |

## 维护

这份文件里的 **"待补充"部分必须由你填**。
涉及具体小区、覆盖情况、高校政策的事实，只能从联通对接人那里拿。

**AI 不能编这些。** 编出来的小区名和覆盖信息，会让用户白跑一趟，
比不发内容更伤账号。
