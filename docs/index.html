Capabilities

一个工作台，跑完获客全流程

从「读别人的求助帖」到「生成回复参考」，每一步都有对应的模块和硬门禁。

🔍

贴吧监控采集

按回复时间倒序拉帖，90 天新鲜度过滤 + 水楼识别，只留可能成交的新帖。

🎯

意向智能分类

靠「求助语气」而非话题词判定 —— 在运营商吧里每帖都提业务名，只看词会命中几百条噪声。

🚫

同行噪声过滤

卡商广告信号稳定（短链 / 返佣 / 平台名 / 模板文案），过滤掉它们，剩下的才是客户。

🧭

浏览器会话管理

每个平台独立 profile，Playwright 驱动。你点进去人工操作，AI 负责巡检与填表。

✍️

内容资产生成

小红书 / 抖音文案、配图、标签一站式生成，填入后台后停下，最后一下由人点。

🛡️

风控红线门禁

内容层（绝对化 / 承诺 / 引流）+ 行为层（互关 / 群 / 同步互动）双扫描，硬拦不放行。

Quick Start

三分钟跑起来

零第三方服务，纯本地。填一个 BDUSS 就能开始采集。

# 1. 依赖
pip install -r requirements.txt
playwright install chromium

# 2. 配置（复制后填 BDUSS）
cp .env.example .env

# 3. 采集 → 分类 → 提醒
python lighthouse/tieba.py --verify
python lighthouse/tieba.py --leads

# 4. 浏览器会话（人工操作）
python lighthouse/浏览器会话管理.py tieba
